**Reading this wiki does not require an account.** We do not provide login, payment, comment, or personal-profile features.

## Features and data

| Feature | What happens |
| --- | --- |
| Site search | Your browser searches the site's static Pagefind index. There is no wiki search-account system. |
| Theme preference | A browser preference can remember your selected light or dark theme. |
| Analytics preference | If analytics is configured, your choice is stored in your browser so optional analytics can stay off unless accepted. |
| Hosting | Cloudflare delivers the site and may process ordinary request information for operation and security. |
| Correction reports | GitHub receives information you choose to include when opening an issue there. |

## Optional analytics

Google Analytics, when configured for this site, loads only after you opt in using the site's analytics preference controls. Declining leaves optional analytics disabled. You can revisit your choice using **Analytics preferences** in the footer when that feature is available.

We do not enable advertising pixels, sell personal profiles, or ask for game credentials.

## External services

Links to Roblox, GitHub, and primary sources take you to those services. Their own policies apply there:

- [Roblox privacy policy](https://en.help.roblox.com/hc/en-us/articles/115004630823-Roblox-Privacy-and-Cookie-Policy)
- [Cloudflare privacy policy](https://www.cloudflare.com/privacypolicy/)
- [GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [Google privacy policy](https://policies.google.com/privacy)

## Contact about this notice

Use the [public repository's issues](https://github.com/jjasnek-ops/steal-anime-egg-wiki/issues) for site questions. Do not post private account data in a public issue. See [About](/about) and [Sources](/sources) for the editorial contact process and the facts we publish.
